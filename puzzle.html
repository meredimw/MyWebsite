03 / THE ARCADE CLASSIC

A Little About the Game

Stack gems. Break gems. Win.

First released in arcades by Capcom in 1996, Super Puzzle Fighter II Turbo brings together miniature fighters from Street Fighter and Darkstalkers for fast-paced puzzle battles.

Build larger Power Gems by combining like-colored gems, then detonate groups with matching Crash Gems. Big clears send Counter Gems to the other side. A well-timed chain can change everything.

How to add a new personal best to this page

The score cards and table are generated from one easy-to-edit list near the bottom of this HTML file. Open the file in a text editor, search for SCORE_ENTRIES, and add another entry using the same format.

  1. Upload the new score screenshot alongside this HTML file (for example ChunLi.jpg).
  2. Add another item to SCORE_ENTRIES with its character, score, difficulty, and image filename. Include max-chain and max-power-gem figures if visible.
  3. Save the HTML and publish it. The page automatically sorts scores from highest to lowest and updates the summary cards.

Screenshot filenames are case-sensitive on many web hosts. The original file is intentionally spelled Donovon.jpg, matching your upload.
